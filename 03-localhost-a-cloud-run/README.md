# 03 · De localhost a Cloud Run con contratos tipados

Carpeta del monorepo público de **AI Native Dev**. Proyecto hilo: **TraderPulse**.

Un BFF en FastAPI y un frontend en Next.js que comparten un contrato OpenAPI, un Dockerfile y una configuración que el agente genera y que verificamos antes de confiar en ellos, y el deploy en [Cloud Run](https://cloud.google.com/run/docs) con [Secret Manager](https://cloud.google.com/secret-manager/docs).
